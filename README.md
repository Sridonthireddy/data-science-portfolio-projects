# Data Science Portfolio Projects

Three self-contained, runnable portfolio projects built to support the CV entries in this folder:

1. `customer-churn-prediction/` — binary classification with EDA, feature engineering, SQL analysis, and model evaluation.
2. `ecommerce-analytics/` — transactional sales, customer, and product analytics with Power BI-ready exports.
3. `movie-recommendation-system/` — content-based movie recommendations using text features and cosine similarity.

Each project generates a deterministic sample dataset locally, so it can run without downloading private or licensed data. See the project-level README before running it.
